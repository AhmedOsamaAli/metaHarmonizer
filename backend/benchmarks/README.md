# Versioned Mapping Benchmarks

`ontology/ncit_disease_efo_v1.csv` is a frozen 200-query subset of the disease
mapping benchmark supplied by Sehyun Oh for project evaluation. The rows retain
their original EFO reference labels and identifiers. The gate evaluates NCIt
predictions by normalized top-1 label because identifiers are not comparable
across the two ontologies.

Version `v1` was generated by de-duplicating `query` from
`om_benchmark_ols_efo_disease.csv` in source order and retaining the first 200
rows. Its SHA-256 is pinned in the adjacent policy file.

The corpus is immutable within version `v1`. Correcting or expanding ground
truth requires a new versioned file and policy so benchmark changes cannot hide
an engine regression.

The policy enforces both an absolute quality floor and a maximum drop from the
currently published KB bundle. KB refresh runs retain before/after summaries,
row-level predictions, and the comparison report as CI artifacts.

The v1 floor was calibrated on 2026-08-13: 200/200 queries produced a match and
62/200 matched the cross-ontology reference label (31.0%). The 29% floor allows
two points of noise below that measurement; the separate before/after rule also
blocks any refresh that drops more than two absolute points from production.
