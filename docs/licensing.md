# Licensing and cBioPortal RFC 86

## Current repository

MetaHarmonizer is currently distributed under the repository's
[MIT License](../LICENSE). Contributions submitted here are made under that
license unless the project adopts a different process through an explicit,
reviewed change.

## cBioPortal relicensing consent

The statement

> I consent to the relicensing of my contributions to the cBioPortal
> repositories from AGPL-3.0 to Apache-2.0 as described in RFC 86.

concerns contributions to cBioPortal repositories participating in that
relicensing process. It does not automatically relicense this independent MIT
repository and should not be inserted here as a substitute for the cBioPortal
project's contributor-consent record.

If you have contributed to affected cBioPortal repositories, record consent
through the exact organization process requested by cBioPortal maintainers. Use
your own identity and verify the scope before consenting. The cBioPortal
organization is available at [github.com/cBioPortal](https://github.com/cBioPortal).

## Future transfer or incorporation

Before moving this project into a cBioPortal repository or incorporating its
code there:

1. Confirm the target repository license and contribution policy with cBioPortal
   maintainers.
2. Inventory contributors and third-party dependencies.
3. Preserve copyright and license notices required by dependencies.
4. Obtain any contributor consents required by the target project.
5. Use an explicit history-preserving transfer or reviewed code contribution;
   do not assume an organization move changes license terms.
6. Update `LICENSE`, package metadata, documentation, and notices only after the
   legal/maintainer decision is recorded.

## RFC 86

The cBioPortal RFC 86 process concerns relicensing contributions in cBioPortal
repositories from AGPL-3.0 to Apache-2.0. This repository is currently hosted
outside the cBioPortal organization and is already MIT-licensed, so that consent
process does not change this repository's present license.

If this work is later copied, transferred, or incorporated into a cBioPortal
repository, cBioPortal may ask contributors to record the statement:

> I consent to the relicensing of my contributions to the cBioPortal repositories
> from AGPL-3.0 to Apache-2.0 as described in RFC 86.

Record that consent in the official cBioPortal process when requested; do not
change this repository's license solely to anticipate a possible future transfer.
Relevant references:

- [cBioPortal relicensing project](https://github.com/cBioPortal/relicensing)
- [RFC 86 tracking issue](https://github.com/cBioPortal/cbioportal/issues/12271)
